# Неделя 5. Решающие деревья: от правил разбиения к важности признаков

## Лекция

- [Интерактивная презентация](https://yuzinyakoff.github.io/classic-ml-course/masters/2026/week-05/slides/)
- [PDF-версия презентации](lecture/slides.pdf)
- [Подробный текст лекции](lecture/chapter.md)
- [Исходник Slidev](../../../presentation/decks/masters-2026-week-05.md)

Устройство и обучение деревьев, RSS/MSE, Gini и энтропия, рекурсивное
построение CART, управление сложностью и свойства деревьев. Затем —
локальный путь объекта, встроенная важность MDI и permutation importance.

В конце презентации находятся 16 дополнительных слайдов: подробное введение
в информацию, двоичные коды и энтропию для самостоятельного изучения.

Иллюстрации текста и общие компоненты презентации переиспользуются из
материалов бакалаврских недель 8–9. При локальном чтении сохраняйте структуру
репозитория, чтобы относительные ссылки на эти материалы работали.
Происхождение материалов указано в [списке атрибуций](../../../ATTRIBUTIONS.md).

## Семинар

- [Студенческий notebook](seminar/seminar.ipynb)
- [Зависимости Python](seminar/requirements.txt)

Код учебного классификатора уже приведён: его читаем, запускаем и исследуем,
сравниваем со `sklearn`, затем проверяем ограничения сложности, CV, MDI и PI.
Notebook опубликован без выполненных outputs.

Данные синтетические и создаются непосредственно в notebook: сетка из 30
точек и 400 шумных наблюдений, полученных с помощью `make_circles`.
Дополнительные CSV и изображения скачивать не нужно.

Для локального запуска установите зависимости командой
`python -m pip install -r requirements.txt` из папки `seminar` и откройте
`seminar.ipynb` в JupyterLab, Jupyter Notebook или VS Code. Выполняйте ячейки
по порядку.
