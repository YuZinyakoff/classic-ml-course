# Проекты — магистратура 2026

Каждый проект посвящён отдельной теме классического машинного обучения.
Постановка, обязательные эксперименты, критерии оценивания и рекомендуемые
источники приведены в соответствующем задании.

| № | Тема |

| 2 | [MLP и backpropagation](mini-project-02.md) |
| 3 | [Прогнозирование временных рядов](mini-project-03.md) |
| 4 | [Классификация текстов](mini-project-04.md) |
| 5 | [A/B, рандомизация и причинный эффект](mini-project-05.md) |
| 6 | [Рекомендательные системы](mini-project-06.md) |

Формат — командное выступление около 20 минут, затем ответы на вопросы.
Можно использовать слайды, notebook, демонстрацию или другие подходящие
средства; формат представления результатов свободный.

Защиты предусмотрены на восьмой встрече курса. Конкретные даты и порядок
выступлений преподаватель объявит отдельно.
