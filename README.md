# Машинное обучение

Открытые материалы вводного университетского курса по классическому машинному обучению.
Курс читается в НИУ ВШЭ — Нижний Новгород в 2026-2027 учебном году.


## Траектории

- [Бакалавриат](bachelors/2026/README.md)
- [Магистратура](masters/2026/README.md)

Материалы публикуются по неделям.

[Интерактивные презентации](https://yuzinyakoff.github.io/classic-ml-course/) доступны на отдельной странице курса.
