# Классическое машинное обучение

Открытые материалы университетского курса по классическому машинному обучению.
Курс читается в НИУ ВШЭ — Нижний Новгород.

Репозиторий является авторским учебным проектом и не представляет официальный
сайт НИУ ВШЭ.

## Траектории

- [Бакалавриат](bachelors/2026/README.md)
- [Магистратура](masters/2026/README.md)

Материалы публикуются по неделям после содержательной и технической проверки.
Для каждой опубликованной недели могут быть доступны конспект лекции,
интерактивная презентация, PDF-версия слайдов, семинар и необходимые данные.
