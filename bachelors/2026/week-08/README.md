В студенческой версии класс `MyDecisionTreeClassifier` оставлен пустым для
последовательного live-coding. Выполняйте проверки после добавления нужных
методов; до реализации класса запуск всего notebook сверху вниз не предусмотрен.

Выполненная версия содержит реализацию, результаты, таблицы и графики.
Она предназначена для самостоятельного изучения и воспроизведения после занятия.

Для локальной работы скачайте notebook и `requirements.txt`, установите
зависимости командой `python -m pip install -r requirements.txt` и откройте
notebook в Jupyter. Отдельные CSV и изображения не нужны: синтетические данные
генерируются в коде, Iris загружается из установленного scikit-learn.

Можно открыть notebooks в Google Colab:
[студенческий](https://colab.research.google.com/github/YuZinyakoff/classic-ml-course/blob/main/bachelors/2026/week-08/seminar/seminar.ipynb)
или [выполненный](https://colab.research.google.com/github/YuZinyakoff/classic-ml-course/blob/main/bachelors/2026/week-08/seminar/seminar_completed.ipynb).
