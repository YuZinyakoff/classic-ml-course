Разбираем, почему прогнозы деревьев меняются при повторном обучении,
как усреднение влияет на разброс и как на этой идее строятся бэггинг
и случайный лес. Завершаем разбором out-of-bag оценки качества.

## Семинар

- [Ноутбук «Случайный лес»](seminar/seminar.ipynb)
- [Зависимости](seminar/requirements.txt)
- [Источник California Housing и офлайн-загрузка](seminar/DATA_SOURCE.md)

Скачайте папку `seminar`. В окружении Python 3.11 или новее,
из которого запускаете Jupyter,
установите зависимости командой `python -m pip install -r requirements.txt`
из этой папки и откройте `seminar.ipynb`. Для воспроизведения чисел из
семинара используйте указанную в зависимостях версию scikit-learn 1.8.0.
Первый запуск загружает данные
через scikit-learn; последующие используют локальный кэш. Архив данных
в репозиторий не входит. Время обучения на вашей машине может отличаться
от чисел, приведённых в тексте семинара.
