# Данные семинара: неделя 1

В папке находятся два набора данных, которые использует
[`seminar.ipynb`](../seminar.ipynb). Файлы уже сохранены локально, поэтому во
время занятия подключение к интернету не требуется.

## `demo-churn.csv`

Небольшой синтетический набор из 16 аккаунтов подписочного сервиса. Он нужен
для первого совместного примера: прочитать таблицу, определить момент прогноза,
разделить данные и построить простую базовую модель.

Целевая переменная `churn_30d` показывает, будет ли подписка отменена в
следующие 30 дней. Столбец `active_days_next_7d` содержит будущую относительно
момента прогноза информацию, поэтому использовать его как признак нельзя.

## `bank-week01.csv`

Учебная версия набора [Bank Marketing](https://archive.ics.uci.edu/dataset/222/bank+marketing)
из UCI Machine Learning Repository: 4521 объект и 11 столбцов.

Авторы исходного набора: S. Moro, P. Rita и P. Cortez. Лицензия —
[CC BY 4.0](https://creativecommons.org/licenses/by/4.0/), DOI:
[10.24432/C5K306](https://doi.org/10.24432/C5K306). В учебном файле сохранены
все строки исходного `bank.csv` и выбран набор из 11 столбцов; значения не
изменялись. Полная запись об атрибуции находится в
[`ATTRIBUTIONS.md`](../../../../../ATTRIBUTIONS.md).
