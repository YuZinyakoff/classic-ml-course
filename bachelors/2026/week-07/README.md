Для локальной работы скачайте всю папку `seminar`: notebook, HTML и
`penguins.csv` должны лежать рядом, а `assets/` и `THIRD_PARTY_LICENSES/` —
внутри неё. Запускайте Jupyter из этой папки. Понадобятся Python, NumPy,
pandas, Matplotlib, seaborn, scikit-learn и joblib.

HTML можно открыть прямо в браузере без Jupyter и доступа к сети.
Студенческий notebook содержит весь учебный код; результаты выполнения очищены.
Файлы моделей в `artifacts/` создаются при выполнении примера и не входят
в комплект. Загружайте `joblib` только из доверенных источников.
