# Данные семинара: источники и подготовка

## Bike Sharing

Исходный набор — *Bike Sharing Dataset*, Capital Bikeshare, Вашингтон,
2011–2012 годы. Авторы — Hadi Fanaee-T и João Gama.
[UCI Machine Learning Repository](https://archive.ics.uci.edu/dataset/275/bike+sharing+dataset),
[DOI 10.24432/C5W894](https://doi.org/10.24432/C5W894),
[CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).

Файл `data/bike_day_prepared.csv` — подготовленная версия исходной дневной
таблицы `day.csv`. Одна строка — один календарный день. Сохранены
исторические наблюдения; исключён один день с нулевой влажностью,
осталось 730 строк.

Преобразования выполнены при подготовке файла:

- температура переведена в °C: исходный нормированный `temp` × 41;
- влажность переведена в проценты: исходный `hum` × 100;
- скорость ветра переведена в км/ч: исходный `windspeed` × 67;
- коды сезонов, погоды, праздников и рабочих дней раскрыты в читаемые
  категории; год и месяц извлечены из даты;
- числовые значения для моделирования не округлялись.

В notebook эти значения читаются как готовые физические величины,
повторное преобразование единиц не требуется. Семинар исследует
обученные предикторы ретроспективно, по уже измеренной погоде;
это не оценка прогнозирования неизвестных будущих дней.

## Diamonds

Набор из `ggplot2` содержит цены и характеристики 53 940 бриллиантов:
одна строка — один камень, `price` — цена в долларах США.
[Описание исходного набора](https://ggplot2.tidyverse.org/reference/diamonds.html),
[описание в plotnine](https://plotnine.org/reference/diamonds.html).

Таблица загружается командой `from plotnine.data import diamonds`
из установленного пакета; отдельный файл Diamonds не распространяется.
В учебном коде удаляются точные дубликаты, исключаются нулевые и
неправдоподобно большие размеры, затем выбирается воспроизводимая
подвыборка из 5000 камней. Все эти действия явно показаны в notebook.
